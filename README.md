# ⚙️ Mecha-Part Finder

Un catalogue intelligent pour trouver rapidement des composants de robotique et de motorisation.

## 🚀 Fonctionnalités
- **Fusion de catalogues** : Regroupe les moteurs CC et les servomoteurs.
- **Recherche temps réel** : Filtrage instantané par mots-clés.
- **Filtres techniques** : Tri par type de moteur et par tension (5V, 12V).
- **Design Modern Tech** : Interface claire, réactive (Responsive) et professionnelle.

## 🛠️ Technologies
- **HTML5 / CSS3** : Mise en page moderne avec Grid et Flexbox.
- **JavaScript (ES6+)** : Logique de filtrage et chargement asynchrone des données JSON.
- **JSON** : Stockage des données produits extraites de Gotronic.

## 📦 Installation
1. Cloner le projet.
2. Lancer `index.html` via un serveur local (ex: Live Server).
